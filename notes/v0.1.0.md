## v0.1.0

**Action requise :** aucune

### Ce qui change

- Première version installable. Un site se crée par `basalte init <nom>`, se
  valide par `npm run check`, se met en ligne par `npm run deploy -- --host <ip>`
  et se monte de version par `npm run update`.
- Le site public est statique et n'embarque aucun JavaScript. L'édition passe
  par un panel servi à côté, sur `/admin` — cinq écrans : édition, médias,
  messages, statistiques, compte.
- Sept blocs de référence : `hero`, `richtext`, `features`, `gallery`,
  `contact`, `faq` et `download`. Plus l'en-tête et le pied de page, qu'un dépôt
  client remplace dossier pour dossier.
- Deux rendus construits depuis le même contenu et servis chacun à son support,
  quand le site déclare la capacité `desktopRender`.
- Le formulaire de contact écrit ses messages en base avant toute notification :
  aucun ne se perd. Il prévient par email, et par une adresse web quand le site
  en déclare une.
- Ce qu'un site fait se déclare dans `site.config.ts` et se change après coup :
  notification des messages, mesure d'audience, documents PDF, second rendu.
- Le référencement est livré avec : carte de partage, données structurées,
  sitemap, `robots.txt`, favicon, page 404, redirections, et le recadrage des
  images au format que leur emplacement déclare.
- Deux documents légaux générés, à compléter, et une page de remerciement après
  l'envoi du formulaire.
- Onze commandes : `init`, `check`, `inventory`, `content`, `lint`, `update`,
  `deploy`, `doctor`, `migrate`, `admin:login`, `update-all`. `doctor` prouve la
  configuration au lieu de la vérifier — il envoie un vrai email, appelle
  vraiment l'adresse de notification, et sonde les enregistrements DNS qui font
  arriver un email. `inventory` dit ce qui est disponible pour écrire, `content`
  ce que le site contient déjà, `lint` ce que le code doit tenir.
- `check` refuse un titre ou une description de page vide dans une langue en
  ligne, une traduction manquante, une image sans texte alternatif. Il avertit
  sans refuser d'un titre repris d'une page à l'autre, d'une page qui se partage
  sans vignette et d'une fiche d'entreprise incomplète.
- Le dépôt généré porte son paquet Claude Code : `CLAUDE.md`, la doc du socle
  régénérée à chaque installation, le contexte du site en `docs/`, et des skills
  d'entretien.
